# Cẩm nang chuyển đổi JavaScript sang Python & Hệ sinh thái AI (Dành riêng cho dự án SLM)

Tài liệu này được thiết kế riêng cho lập trình viên đã quen với JavaScript/TypeScript và đang học Python (qua Exercism) để bước vào lập trình AI với PyTorch.

## 1. Bản đồ tư duy: Từ JavaScript sang Python

Khi chuyển từ JS sang Python để làm AI, bạn không cần học lại tư duy lập trình mà chỉ cần "ánh xạ" các khái niệm tương đương và nắm những điểm khác biệt dễ gây bẫy (gotchas).

### 1.1. Bảng ánh xạ nhanh (JS vs Python)

| Khái niệm | JavaScript / Node.js | Python (3.11+) | Lưu ý trong dự án SLM |
| --- | --- | --- | --- |
| Quản lý gói & Môi trường | `npm / pnpm, package.json, node_modules (cục bộ theo thư mục)` | `pip / uv, requirements.txt hoặc pyproject.toml, venv` | Python mặc định cài gói toàn cục (global)! Bắt buộc tạo .venv trước khi pip install. |
| Khai báo biến | `const, let` | `Không có từ khóa, gán trực tiếp: x = 10` | Dùng quy ước viết hoa MAX_SEQ_LEN = 512 cho hằng số. |
| Kiểu dữ liệu tĩnh | `TypeScript (x: number)` | `Type Hints (x: int, def fn(a: Tensor) -> Tensor:)` | Python không báo lỗi kiểu lúc chạy (runtime), nhưng Type Hints cực kỳ quan trọng để IDE gợi ý hàm PyTorch. |
| Cấu trúc dữ liệu | `Array ([]), Object ({}), Map, Set` | `list ([]), dict ({}), tuple (()), set` | Trong Python, key của dict phải viết trong nháy: {"lr": 3e-4} (trừ khi dùng dict(lr=3e-4)). |
| Giải nén (Unpacking) | `Destructuring: const [a, b] = arr; const {x} = obj;` | `Tuple/List Unpacking: B, T, C = x.shape` | Cực kỳ phổ biến trong PyTorch để lấy kích thước Tensor! |
| Spread / Rest | `...args, {...obj}` | `*args (tuple), **kwargs (dict)` | Dùng suốt ngày khi truyền config vào model: SLMModel(**config_dict). |
| Hàm ẩn danh | `Arrow function: (x) => x * 2` | `lambda x: x * 2` | Chỉ dùng cho biểu thức 1 dòng. Nên ưu tiên def hoặc List Comprehension. |
| Xử lý mảng (map, filter) | `arr.map(x => x * 2).filter(x => x > 0)` | `List Comprehension: [x * 2 for x in arr if x > 0]` | Cách viết chuẩn Pythonic, nhanh và gọn hơn map/filter. |
| Lập trình hướng đối tượng (OOP) | `class, constructor(), this.prop` | `class, def __init__(self):, self.prop` | Trong Python, self phải được truyền tường minh làm tham số đầu tiên của mọi method! |
| Giá trị rỗng | `null, undefined` | `None` | Kiểm tra rỗng chuẩn: if mask is None: (dùng is thay vì ==). |
| Truthy / Falsy | `[] và {} là Truthy!` | `[], {}, "", 0, None đều là Falsy!` | Cẩn thận! Trong JS if ([]) chạy vào nhánh true, còn Python if []: là false. |

## 2. Giáo trình 5 Mô-đun Thực chiến Python gắn liền Dự án SLM

Thay vì học lý thuyết rời rạc, việc học Python của bạn được chia làm 5 mô-đun khớp trực tiếp với từng chặng code SLM:

### Module 1: Môi trường, Biến, Truthy/Falsy & Hàm (Phục vụ Ngày 1–2)

- Từ npm sang .venv: Cách tạo môi trường cô lập python -m venv .venv, kích hoạt và khóa gói pip freeze.
- Tham chiếu bộ nhớ (Names & Binding): Biến trong Python là "nhãn dán" trỏ tới vùng nhớ, không phải chiếc hộp cố định. Hiểu sự khác biệt giữa kiểu bất biến (int, str, tuple) và khả biến (list, dict, Tensor).
- Bẫy Truthy/Falsy & Toán tử logic: Dùng and, or, not thay cho &&, ||, !. Dùng is None / is not None thay cho === null.
- Hàm, Default Arguments & Type Hints: Cách viết def check_gpu(min_vram_gb: float = 10.0) -> bool: và tránh bẫy "Mutable Default Argument" (def fn(items=[]) là đại kỵ trong Python!).

### Module 2: Chuỗi, List Comprehension, Generators & File I/O (Phục vụ Ngày 3–4 — Pipeline 3 Tầng Dữ liệu)

- Xử lý chuỗi & Unicode tiếng Việt: f-strings, .strip(), .split(), .join(), và chuẩn hóa dấu tiếng Việt với unicodedata.normalize("NFC", text).
- List/Dict/Set Comprehensions: Thay thế hoàn toàn .map() và .filter() của JS khi lọc văn bản 3 tầng dữ liệu.
- Generators & từ khóa yield: Ánh xạ từ function* trong JS. Dùng để đọc streaming hàng trăm nghìn bài Wikipedia và Cosmopedia qua mạng mà RAM chỉ tốn vài trăm MB.
- Context Manager (with open(...)): Đọc/ghi định dạng .jsonl (JSON Lines) an toàn, tự động đóng luồng file.

### Module 3: Slicing Đa chiều, Tuple Unpacking & @dataclass (Phục vụ Ngày 4–5 — Dataset & Config)

- Slicing nâng cao [start:stop:step]: Cắt mảng 1 chiều và nhiều chiều. Nắm chắc tokens[:-1] (lấy đầu vào x) và tokens[1:] (lấy nhãn y dịch phải 1 bước).
- Tuple Unpacking & Extended Unpacking: B, T, C = logits.shape hoặc first, *middle, last = items.
- @dataclass: Mang sự chặt chẽ của TypeScript interface vào Python để quản lý SLMConfig và TrainConfig sạch sẽ, không sợ gõ sai tên key của dict.

### Module 4: OOP Chuẩn PyTorch & Dunder Methods (Phục vụ Ngày 5–7 — Tự viết Transformer)

- Cấu trúc Class & self: Tại sao Python bắt truyền self vào mọi phương thức? Cách gọi super().`__init__`() khi kế thừa torch.nn.Module.

**Các Dunder Methods (Magic Methods) cốt lõi:**

- `__init__`(self, ...): Khởi tạo các tầng (nn.Linear, nn.LayerNorm, nn.Embedding).
- `__call__`(self, *args): Bí mật đằng sau việc gọi logits = model(x) thay vì model.forward(x).
- `__len__`(self) và `__getitem__`(self, idx): Hai hàm bắt buộc để tự viết PretrainDataset và SFTDataset.

### Module 5: Context Managers nâng cao, Exception, Async & Pydantic (Phục vụ Ngày 8–14 — Training & FastAPI)

- Context Managers trong GPU: with torch.no_grad():, with torch.inference_mode():, và with torch.amp.autocast(device_type="cuda", dtype=torch.bfloat16):.
- Quản lý ngoại lệ (try / except / finally): Cách bắt lỗi tràn VRAM (torch.cuda.OutOfMemoryError) để tự động giảm microbatch_size.
- Async/Await & asyncio.Lock: Tương đương Promise / mutex trong Node.js, dùng để khóa 1 lượt sinh văn bản đồng thời trên GPU.
- FastAPI + Pydantic: Tương đương Express/Fastify + Zod, dùng để kiểm tra đầu vào tự động và trả lỗi 422 khi prompt rỗng hoặc vượt quá 512 tokens.

## 3. Bản đồ Hệ sinh thái AI trong dự án SLM

Bạn không cần học hàng chục thư viện. Dự án này chỉ xoay quanh đúng 5 trụ cột:

### PyTorch (torch, torch.nn, torch.nn.functional):

Đóng vai trò như "NumPy có gắn GPU + Tự động tính đạo hàm (Autograd)".

Bạn sẽ dùng nó để viết kiến trúc Transformer, hàm mất mát (Cross-Entropy), và vòng lặp huấn luyện.

### Hugging Face datasets:

Dùng để kéo dữ liệu 3 Tầng Ngữ Nghĩa (wikimedia/wikipedia Anh–Việt, HuggingFaceTB/smollm-corpus) ở chế độ streaming=True, không làm đầy ổ cứng.

### Hugging Face tokenizers:

Thư viện viết bằng Rust cực nhanh để huấn luyện bộ từ điển Byte-level BPE 8.192 tokens cân bằng giữa ngôn ngữ giải thích phổ thông và thuật ngữ AI/CS.

### FastAPI + Pydantic + Uvicorn:

Phục vụ REST API và giao diện HTML demo tối giản.

### Pytest:

Giống Jest / Vitest bên JS. Dùng để viết các bài kiểm thử tự động cho Tokenizer round-trip, Causal Mask, và Save/Load checkpoint.
